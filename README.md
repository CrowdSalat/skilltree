# Skill Tree

A minimal, zero-dependency visual hierarchy tree for screening CV buzzwords against an application development taxonomy.

Open on: [](https://crowdsalat.github.io/skilltree/)

---

## Quick Start (Run Locally)

### Option 1: Python Built-in Web Server (Recommended)
Open your terminal in the project directory and run:

```bash
# Python 3
python3 -m http.server 8000

# Or Python 2
python -m SimpleHTTPServer 8000
```

Then open `http://localhost:8000` in your web browser.

### Option 2: Direct File Open
Double-click `index.html` to open it directly in any browser (`file:///...`). But then skills.txt is not loaded but the inline version is used.
